# Arsip desain

`iterations/` berisi catatan implementasi, validasi, dan rancangan dari iterasi hero, login, serta landing sebelumnya. `visuals/` berisi konsep visual; `visuals/source/` menyimpan PNG sumber untuk gambar WebP yang digunakan situs.

Dokumen ini menjadi rekam proses, bukan daftar pekerjaan yang masih harus dijalankan. Rancangan landing terbaru berada di [landing-redesign.md](../landing-redesign.md), token aktual berada di [tokens.css](../../assets/css/tokens.css).
