# Video SIMINAT

- `siminat-dinamis/`: versi terbaru, 1080 × 1920, sekitar 42 detik. Alur masalah, panduan nasional dan guru BK, lalu solusi SIMINAT.
- `archive/siminat-pengenalan/`: versi pengenalan sebelumnya, termasuk komposisi landscape, draft portrait, aset dan MP4 lama. Dipindahkan utuh agar tetap dapat disunting atau dirender ulang.

Setiap proyek menyimpan asetnya sendiri. Salinan musik di tiap proyek diperlukan agar proyek video dapat dipindahkan secara mandiri. File MP3 duplikat di root aplikasi sudah dihapus setelah hash SHA-256 dicocokkan.

Cache thumbnail dan waveform dapat dibuat ulang oleh HyperFrames dan diabaikan Git. State editor dan history di `.hyperframes/` dipertahankan.
